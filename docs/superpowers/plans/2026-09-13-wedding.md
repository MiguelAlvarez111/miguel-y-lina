# Wedding Invitation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Publicar hoy la invitación de Miguel y Lina en Railway con fotos reales, calendario, Maps, personalización y RSVP desacoplado.

**Architecture:** Astro genera HTML estático desde configuración TypeScript. Scripts pequeños añaden countdown, saludo, galería y motion. Un proveedor externo recoge RSVP; no se inventa una URL ni almacenamiento.

**Tech Stack:** Astro 5, TypeScript, CSS, Vitest, Playwright, sharp, fuentes locales; Railway Railpack.

**Spec:** docs/superpowers/specs/2026-09-13-wedding-design.md

## Global Constraints

- Contenido específico centralizado en src/config/wedding.ts.
- Fecha confirmada: 2026-09-19T19:00:00-05:00; America/Bogota.
- Club de Comercio, Salón Ciudad de Cúcuta; Maps https://maps.app.goo.gl/SGfUkc2BEFvSSrhG9.
- HTML completo y SEO en build; URLs absolutas y canonical sin query.
- prefers-reduced-motion, teclado, targets 44 px, sin scroll hijacking.
- No secretos ni listado privado de invitados en el repositorio.
- Siete HEIC originales permanecen intactos; exportaciones sin EXIF en sitio.
- Dress code elegante sin etiqueta rigurosa, regalos opcionales, revelación de sexo durante evento.
- Railway CLI autorizado para crear proyecto, servicio, dominio y desplegar.
- RSVP Tally aprobado pero falta URL concreta; no simular recepción exitosa.

## Archivos e interfaces

src/lib/event.ts: Countdown {days,hours,minutes,seconds,status}, countdown(target:string,now:number), guestContext(search:string): {name:string,inviteId:string|null}, calendarUrl(event:CalendarEvent), calendarIcs(event:CalendarEvent), providerUrl(url:string): string|null. CalendarEvent {title,start,end,location,description,url}.
src/config/wedding.ts: export wedding con todo el contenido y fotos; fechas y textos se consumen en componentes.
src/components/{Hero,Invitation,Story,Schedule,Gallery,Rsvp,Closing,Photo}.astro: presentación por sección.
src/layouts/Layout.astro: metadatos, fuentes y shell.
src/scripts/invitation.ts: saludo, countdown, dialog, reveals.
src/pages/{index.astro,boda.ics.ts}: documento y calendario generados.
src/styles/global.css: tokens, layout, responsive y animaciones.
scripts/prepare-photos.mjs: formatos y tamaños de entrega sin metadata; scripts/start.mjs: servidor estático mínimo con MIME, cache, seguridad de ruta y PORT.
